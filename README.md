# Multi-Website Dashboard

A standalone browser dashboard that displays multiple websites in movable mini-browser panels.

## Features

- Add website URLs and automatically save them in the browser
- Edit and reload individual website panels
- Reload all panels at once
- Open a website in a separate tab
- Fullscreen individual panels
- Drag panels to rearrange them
- **Fit All** mode to keep every panel visible on one screen
- **Comfortable** mode for larger scrollable panels
- Responsive mobile layout
- No framework, build system, or external dependencies

## Run it

Open `index.html` in a modern browser, or host this repository with GitHub Pages.

> Note: Some websites prevent themselves from being embedded in iframes. Those sites can still be opened with the panel's external-link button.
